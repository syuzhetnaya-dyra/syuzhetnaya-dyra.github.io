# 05. Вкладка III «Тест-дыра»

## Что на сайте сейчас
Подпись: «Сюжетный чек пройден не весь: осталось N из 6. Это не запрещает тест - но ловушки здесь рассчитаны на то, что досье уже разобрано». Три задания идут подряд (на странице «Ионыча»: 3 + 21 + 10 = 34 типовых задания).

### Задание № 1. Род, жанр, направление
Три вопроса с вводом ответа с клавиатуры («регистр и окончания не придираются»):
1. Жанр: «К какому жанру относится произведение А. П. Чехова «Ионыч»?»
2. Литературный род: «Укажите литературный род, к которому относится произведение ...»
3. Направление: «Назовите литературное направление, в русле которого развивалось творчество А. П. Чехова и к которому принадлежит произведение «Ионыч»».
Кнопка «Проверить», счётчик «Отвечено 0 из 3».

### Задание № 2. Сопоставление (21 вариант, порядок каждый раз новый)
Эталон: тема «СУДЬБА», инструкция «Установите соответствие между героем и его жизненным выбором». Слева позиции А, Б, В (3 героя или 3 состояния героя, например «Екатерина Ивановна (в молодости)», «Екатерина Ивановна (после возвращения)», «Дмитрий Старцев»). Справа 4 варианта, из них ОДИН ЛИШНИЙ: он принадлежит тому, кого в левом столбце нет (в эталоне это фраза про писательство Веры Иосифовны; такая цитата была в варианте 3). Ученик выбирает цифру для каждой позиции, внизу «Цифры в порядке позиций», «Заполнено 0 из 3», «Проверить». Это точная копия формата настоящего задания 2 ЕГЭ.

### Задание № 3. «Другой термин» (10 вопросов, показываются по одному)
Фрагмент-описание из текста, ученик вводит литературоведческий термин. Эталон: описание острого столкновения взглядов героя и среды, ответ «конфликт».

## Типы задания 2 в реальных КИМ (что подтверждено источниками)
- Портретные характеристики героев (ФИПИ МР-2024, «Обломов»: Обломов, Штольц, Захар; 4 портрета, ответ 321).
- Факты жизни героев (ФИПИ МР-2024, «Отцы и дети»: Николай Петрович, Аркадий, Павел Петрович; ответ в источнике не приведён).
- Факты дальнейшей судьбы (ФИПИ МР-2024, «Гроза»: Борис, Варвара, Тихон; ответ в источнике не приведён).
- Действия персонажей по отношению к герою («Война и мир», демоверсия 2026; по вторичному источнику, сверить с PDF).
- Высказывания персонажей («Отцы и дети», демоверсия 2027; по вторичному источнику, сверить с PDF).
- Сторонние банки задач добавляют: герои и главы, социальное положение, характеристики. Они не официальные, использовать как идеи.
Фрагменты и ответы ФИПИ НЕ копировать в продукт: формулировки, фрагменты и цитаты составлять самостоятельно по тексту произведения.

Рекомендуемая раскладка 21 задания для крупной работы (подгонять под факты, а не наоборот): портреты 3, факты жизни 4, судьба 3, высказывания и реплики 4, отношения и действия 4, места, предметы, детали 3. Для малой прозы - минимум 8 заданий без натяжек.

## Как проверять «лишний вариант»
Лишний вариант - реальный факт о другом герое этого же произведения (не выдумка), он не подходит ни одной из трёх позиций. Правильно: ученик не может отгадать методом исключения, потому что лишний вариант правдоподобен. Claude Code обязан указать `extra_owner`.
