### Виды карточек (подробнее в файле 02)
- Полная карточка: досье + блок вопросов в чеке + картинка героя.

4. Номер главы сверять по тому же изданию, из которого взята цитата. Если нумерация в изданиях различается, пиши по основному изданию и поле `source`. Для «Молодой гвардии» сначала выбери редакцию (1945 или 1951) и запиши выбор в журнал: главы различаются.

6. Поля `verified` и `source` заполняются в каждой строке. `verified: true` только после сверки. Всё несверенное не попадает в билд для публикации; в черновом режиме подсвечивается.

## Принципы вопросов (по логике ЕГЭ)
- Проверяем знание текста, не эрудицию. Типы соответствий: портретные характеристики, факты жизни, факты судьбы, действия по отношению к другому герою, высказывания, имения и места, отношения.
- Дистракторы правдоподобные и из того же произведения. Нельзя «очевидно глупый» вариант.
- Один вопрос - один факт. Если героя можно трактовать двояко, вопроса не будет.
- Язык нейтральный, как в КИМ. Без оценок вроде «самый яркий герой».
- Тексты на сайте пиши обычными дефисами, без длинных тире в подписях к вариантам и без стрелок; сохраняй стиль страниц «Ионыча».
