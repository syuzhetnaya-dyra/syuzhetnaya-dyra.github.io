# ЧАСТЬ D

# 04. Вкладка II «Сюжетный чек»

## Что на сайте сейчас
- Стартовая страница: список героев римскими цифрами с числом вопросов (Туркин 6, Вера Иосифовна 5, Екатерина Ивановна 6, Старцев 10, Прислуга 4, «Финал рассказа» 1 = 32). Подпись: «Вопросы идут по героям - по тем же фактам, что в досье. Закройте всех, и откроется тест-дыра».
- Прохождение героя: сверху «ВСЕ ГЕРОИ» и счётчик «I из 10», имя героя с вырезанным портретом, вопрос, три варианта ответа.
- После выбора появляется вердикт «ВЕРНО» (или «НЕ ВЕРНО»), под ним пояснение в 1-2 предложения и кнопка «Следующий вопрос». Неверные варианты гаснут.
- Блок «Финал рассказа» - один вопрос про развязку, не привязанный к герою.

## Эталонный вопрос (уже на сайте)
Герой: Дмитрий Старцев. Вопрос: «Какое прозвище у Дмитрия Старцева?» Варианты: «Котик» / «Ионыч» / «В рассказе не указано». Верно: «Ионыч». Пояснение: «Котик - домашнее имя Екатерины Ивановны. Прозвище героя вынесено в заглавие рассказа.»
Принципы, видимые из эталона: ровно 3 варианта; один вариант - правдоподобная подмена (прозвище другого героя); третий - «В произведении не указано»; пояснение объясняет, почему неверный вариант неверен, а не только называет верный.

## Контракт данных
```yaml
work: otcy-i-deti
hero: bazarov            # slug карточки из файла 02, либо "final"
order: 1
questions:
  - id: bazarov-01
    q: "..."
    options: ["...", "...", "..."]   # ровно 3
    correct: 1                       # индекс 0-2
    explanation: "..."               # 1-2 предложения
    fact_ref: {card: bazarov, row: "Внешность"}   # обязательно: каждый вопрос привязан к строке досье
    verified: false
    source: ""
```

## Правила составления
1. Каждый вопрос строится ТОЛЬКО на факте из досье (поле fact_ref). Нет строки в досье - нет вопроса.
2. Вопросы идут от простого к сложному: имя и роль -> занятие и положение -> внешность -> ключевые поступки -> судьба.
3. Типы дистракторов: подмена героя (чужой факт), подмена главы/места, «слишком красивая» формулировка критика вместо текста, «В произведении не указано» (его ставить верным только если факта действительно нет в тексте).
4. «Не указано» не использовать, если нужно проверить память о сюжете, иначе ученик научится отвечать наугад.
5. Количество: главный герой 8-10 вопросов, второстепенный 3-6, групповая карточка без вопросов, плюс 1-2 вопроса «Финал произведения».
6. Нельзя задавать вопрос, на который можно ответить без чтения (общеизвестная фраза «Базаров - нигилист» не считается фактом задания).
